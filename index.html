ODD ATLAS Uploader

The publishing tool behind the Odd Atlas YouTube channel — surprising, true geography facts in under a minute.

What this app does

Odd Atlas Uploader is a private tool used only by the owner of the Odd Atlas YouTube channel. With the owner's permission (Google sign-in), it uses the YouTube Data API and YouTube Analytics API to:

  • upload the channel's own original Shorts and set their titles, descriptions and thumbnails;
  • read the channel's own video statistics to plan better videos;
  • post and reply to comments on the channel's own videos.

It is not offered to other users and does not access any other channel.
